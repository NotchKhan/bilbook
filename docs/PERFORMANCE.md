# Скорость BilBook — 22 октября 2026

## Изменения

- Формы входа/публикации и управление школой загружаются по требованию через next/dynamic.
- В ленте независимые запросы количества реакций, собственных реакций и авторов выполняются параллельно. Все запросы используют прежний клиент с RLS.
- Одновременные одинаковые GET объединяются только на время выполнения. После ответа запись удаляется; при начале и окончании изменения данных или авторизации очередь очищается. Постоянного клиентского кэша школьных данных нет.
- Первое фото ленты загружается с высоким приоритетом; остальные фото и аватары — лениво. Обновление объекта сессии с тем же ID больше не перезапускает запрос историй.
- Новые аватары ограничены 256 px, новые фото новостей/историй — 1440 px, WebP quality 76. Вложения обращений сохраняют 1600 px / quality 78. Клиент и сервер используют общую политику. Уже загруженные школьные файлы не переписывались.
- Демо-фотографии перекодированы в WebP, истории используют отдельные 160 px миниатюры. Оригинальные PNG остаются исходниками для scripts/optimize-demo.mjs.
- Только публичные иллюстрации /demo/* обходят проверку сессии и кэшируются браузером/CDN. Закрытые /api/media, обращения, сессия и JSON остаются no-store; время действия подписанных ссылок не увеличено.
